# Book Companion Releases
To get to the releases, click on Releases on the right. Under Assets you'll see downloads for Android and Windows and the link to the webversion.

## Usage
First, you need to select a book at the top. With a book selected, you can add data by clicking on the button with the plus. Then you set the page that you're currently on. You will then be shown only the information that has been revealed up to the page you selected. If an information changes over the course of the book you will see the version that is valid up to the selected page.

Book Companion differentiates between Entities, Facts and Events.
An Entity is either a character or a place that has facts linked to it. Facts are further split into attributes and relationships. An attribute is a key-value pair for a specific information about one entity (e.g. Birthday: 01.01.1970) while a relationship describes a connection between two entities (e.g. Married). It can have a direction (e.g. Alice loves Bob, but Bob doesn't love Alice) or symmetric (like with Married). An event is simply something that happens in the book but doesn't introduce/change a fact (e.g.  Hagrid takes Harry to Diagon Alley to buy his school supplies).

There are three main pages
### Relationships
Shows all characters and relationships. You can zoom and pan. If you click on a character, you'll see all the facts in the details panel
### Map
Shows all places. Just like with characters you can click on a place to see all the facts about it. Additionally, you can enter edit mode to add new places or adjust their position for when you want to represent the distances or directions between them.
### Events
Shows a list of all events in page order
